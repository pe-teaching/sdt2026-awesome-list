# Professional

- [roadmap.sh](https://roadmap.sh) - step-by-step learning paths for developer roles, useful to plan what to learn next.
- [GitHub Student Developer Pack](https://education.github.com/pack) - free developer tools for students, including GitHub Copilot and cloud credits.
- [JetBrains Kairos](https://kairos.jetbrains.com/) - research and essays on how AI is changing software development. Developer surveys, benchmarks, datasets, and experiments on human–AI coding and next-generation developer tools.
- [Hyperskill](https://hyperskill.org/courses) - learning new coding skills with project based courses
- [build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) - a collection of tutorials for building your own implementations of various software, frameworks, and tools.
- [codeforces.com](https://codeforces.com) - a leading competitive programming platform with useful tutorials and weekly contests.
- [Notion](https://notion.com) - use it to schedule tasks, divide roles, write to-do items as all. If you do video editing, teach students, or anything like that. You can use it.
- [Atcoder](https://atcoder.jp/) - another competitive programming platform with weekly contests and useful problem sheets.
- [regex101](https://regex101.com) - test and debug regular expressions with a live explanation of each part.
