# Study
## Software & Note-Taking Tools
- [Anki](https://apps.ankiweb.net) - flashcards with spaced repetition, good for terms and formulas before exams.
- [Obsidian](https://obsidian.md) - markdown notes with private storage that supports LaTeX and code formatting, great for class notes and self-organisation.
- [Typst](https://typst.app/) - a modern typesetting system that simpler than LaTeX, but still supports math and code formatting. Great for writing reports and notes.
- [Toggl Track](https://toggl.com) - versatile time tracker, with tracking of individual projects and possibility to enable billing control. Mobile app version is the best for studying.
## Computer Science & Programming Courses
- [The Missing Semester](https://missing.csail.mit.edu) - MIT course on the shell, git and editors: the tools other courses expect you to know.
- [freeCodeCamp](https://www.freecodecamp.org/learn) - On this platform you can access free interactive coding lessons and projects that will help you learn programming and practice web development
- [From Nand to Tetris](https://www.nand2tetris.org/) - a course on building a computer from the ground up, from logic gates to operating systems.
- [Command Line Murderers](https://github.com/veltman/clmystery) - a game designed for learning the basics of the terminal and it's commands. It resolves around a murder mystery.
## Competitive Programming & Algorithms
- [USACO Guide](https://usaco.guide) - A collection of competitive programming tutorials and many problems to practice with.
- [USACO](https://usaco.org) - free, structured competitive programming curriculum from beginner to advanced, with problems sorted by topic and difficulty, good for learning algorithms systematically.
## Language learning
- [Duolingo](https://www.duolingo.com) - a language learning platform with interactive lessons, daily challenges, and gamified exercises.
- [Memrise Community Wordlists](https://community-courses.memrise.com/) - user-created flashcards and vocabulary decks for language learning. (free account required)
