# Study

- [Anki](https://apps.ankiweb.net) - flashcards with spaced repetition, good for terms and formulas before exams.
- [The Missing Semester](https://missing.csail.mit.edu) - MIT course on the shell, git and editors: the tools other courses expect you to know.
- [Toggl Track](https://toggl.com) - versatile time tracker, with tracking of individual projects and possibility to enable billing control. Mobile app version is the best for studying.
- [Obsidian](https://obsidian.md) - markdown notes with private storage that supports LaTeX and code formatting, great for class notes and self-organisation.
- [Duolingo](https://www.duolingo.com) - a language learning platform with interactive lessons, daily challenges, and gamified exercises.
